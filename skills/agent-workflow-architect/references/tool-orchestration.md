# 工具调用与效率编排

工具不是模型想起什么就调用什么。先定义工具契约和依赖图，再执行并验证业务效果。

## 工具契约

每个关键工具记录：

```yaml
purpose: 能解决什么问题
boundary: 明确不能做什么
inputs: 必填字段、类型和来源
preconditions: 调用前必须成立的事实
effects: 只读、工作区写入、外部写入或不可逆
success_signal: 业务成功如何确认
failure_signals: 错误、拒绝和部分成功如何识别
idempotency: 重复调用是否安全，使用什么唯一键
timeout_resolution: 超时后怎样查询真实状态
authorization: 谁授权、允许的主体/目标/动作/参数范围、有效期与撤销状态
approval: 现有授权不能覆盖时，需要谁批准及确认绑定的动作版本
evidence: 保存哪些调用、结果和关联标识
```

“工具可用”不等于“当前 Agent 被授权使用”，也不等于“返回 200 就完成业务动作”。

## 调用图

1. 从最终业务结果反推需要哪些事实和动作。
2. 为每个节点写前置条件和输出。
3. 标记读写资源、副作用和审批点。
4. 只有没有数据依赖、写入冲突和顺序约束的节点才能并行。
5. 为每个副作用节点添加结果确认和失败分支。

典型顺序：

```text
解析请求 → 查询权威状态 → 校验规则与有效授权 → 必要时取得审批
→ 执行副作用 → 查询或核对业务结果 → 记录证据
```

## 护栏位置

关键约束要放在最接近风险的位置：

- 用户输入检查不能替代每次工具调用的参数检查。
- Agent 最终输出检查不能证明中间副作用安全。
- 资金、删除、消息发送和权限变更应在工具边界进行代码级校验或审批。
- 即使模型被要求“必须先查询”，代码仍应拒绝缺少查询证据的写入。

不要假设 Agent 级护栏会自动覆盖每个工具、交接或内置执行通道。审查实际运行路径。

## 权限与目标解析

权限按风险逐级提高：只读、工作区写入、外部写入、高风险或不可逆操作。

调用前：

- 将模糊名称解析成唯一目标，必要时让用户确认。
- 使用最小权限和最小数据范围。
- 读取当前状态，避免基于陈旧假设覆盖变化。
- 对批量操作先预览数量、样例和影响范围。

授权一个目标不代表授权相邻系统、所有记录或后续重复操作。按实际影响、环境、范围、可逆性与数据敏感程度判断风险，不能仅凭“发邮件”“改数据库”等动作名称划档；只读也可能涉及敏感数据或数据外传。

区分可自动执行、限定范围自动执行、执行前审批和禁止自动执行，并说明适用条件。有边界的预授权可覆盖后续动作；只有目标、关键参数、环境或范围改变到不再被授权覆盖，或授权过期、撤销时，才需要重新取得授权。不要用模糊的总开关，也不默认让所有写入重复确认。

## 授权生命周期与确认内容

授权记录应能回答：谁批准、授予哪个执行主体、可读写哪些资源、允许哪些动作及参数范围、是否允许委派、何时生效/过期、如何撤销、适用的任务或策略版本。最小权限限制在工具或服务边界执行，子 Agent 不能从自然语言交接中自行获得新权限。

需要确认时，先准备可审阅的产物或动作预览，展示：具体动作、唯一目标、环境、关键参数/变更、影响范围、依据、可逆性或补救方式。只在决定前展示必要信息，用“发布此版本”“发送这封邮件”等具体操作名，避免只有“是否继续”。

批准绑定动作与输入版本或明确的参数范围。执行前再次验证授权、目标当前状态与关键参数；预览后发生实质变化时旧批准不得套用到新动作。记录批准、拒绝、过期与撤销；拒绝时暂停相关分支而非反复追问。

撤销后阻止后续调用，正在执行的动作单独查询与处理。操作审计保留必要身份、时间、目标、版本、授权引用、请求标识及业务结果，按权限与保留期保存，不记录密钥和无关敏感原文。

## 返回校验

把工具结果当作待验证数据：

- 校验结构、必填字段、类型和业务错误码。
- 区分“请求已接收”“处理中”和“业务已完成”。
- 检查时间范围、分页、截断和数据新鲜度。
- 对关键事实进行权威来源查询或读后核对。
- 保存请求 ID、幂等键、目标 ID 和结果状态，便于追踪。

## 效率策略

- 先用便宜的只读检查缩小范围，再调用昂贵模型或外部服务。
- 复用带来源和有效期的已验证结果。
- 批处理相同工具的独立读取，但不要把高风险写入塞进不可审查的大批量。
- 为模型轮次、工具次数、费用和总时长设置预算与停止条件。
- 只有独立节点并行；不要为降低延迟牺牲正确顺序。

## 可观测性

一次业务运行应能串起：用户请求、使用的模型或 Agent、关键判断、工具调用、审批、交接、错误、重试和最终结果。日志应避免泄露敏感输入；记录必要标识和摘要，而不是无边界保存全部内容。
